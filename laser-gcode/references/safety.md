# 激光加工安全清单

这是 `laser-gcode` 的完整安全说明。参数可以慢慢调，安全事故一次就够。
给用户交付 G 代码时，按材料勾选对应条目转述，不要只丢文件路径。

## 1. 火灾（最高频的事故）

- **人不能离开机器**。二极管激光在纸板、MDF、毛毡、织物上可能在几秒内引燃，
  而火焰往往从工件背面开始，正面完全看不出来。
- 机器旁常备：灭火器或湿毛巾、能立刻断电的开关位置、不易燃的台面。
- 切割**不要把工件直接放在木板/纸板上**（垫板本身会被点着），用蜂窝板或金属垫板。
- 加工结束后继续观察 1–2 分钟，暗火可能在停机后才冒烟。
- 已碳化的材料更容易复燃：同一处反复烧（多遍切割）时提高警惕。
- 排烟管道出口不要朝向可燃物/窗帘。

## 2. 眼睛与皮肤

- **不要直视激光光斑**，包括工件上反射的散射光。木材/亚克力/铝表面都会反射。
- 使用与激光波长匹配（通常 445nm 蓝光）的防护镜；
  普通墨镜、太阳镜不防护，反而因瞳孔放大更危险。
- 优先给机器加**封闭外罩（enclosure）**；有外罩时绝大多数散光被挡住。
- 戴上外罩观察窗 ≠ 防激光玻璃：确认观察窗本身是激光防护材质。

## 3. 烟气与材料毒性

**绝对不要加工**（会释放剧毒/腐蚀性气体）：

| 材料 | 释放物 | 后果 |
|---|---|---|
| PVC / 乙烯基 / 仿皮 / 电线皮 | 氯气、氯化氢 | 腐蚀机器、灼伤呼吸道 |
| ABS、聚碳酸酯、聚苯乙烯 | 氰化氢、苯类 | 剧毒 |
| 含铬鞣制皮革（chrome-tanned） | 六价铬 | 致癌、剧毒 |
| 玻纤、碳纤维、CFRP | 微米级粉尘 | 肺损伤，且无法用激光切透 |
| PTFE（特氟龙） | 氟化氢 | 剧毒 |
| 任何未知塑料 | 未知 | 先查材质，宁可不做 |

**必须通风**：MDF、皮革（植鞣）、亚克力、毛毡、织物、橡胶类。
排烟要排到室外，而不是“放在窗边”。室内净化器只能减少气味，不能替代排风。

**可以加工但要注意**：木材（含胶水的胶合板烟大）、纸张/纸板（易引燃）、
阳极氧化铝（只能打掉氧化层，不产生切割烟但会有金属粉尘）。

## 4. 机器与工件

- **焦距**：每次换材料、换镜头、换高度都重新对焦；焦距偏差是“参数不准”的头号原因。
- **气泵（air assist）**：切割必开，能显著减少焦边与火焰；雕刻可调小以保留细节。
- **$32=1（laser mode）**：GRBL 必须打开激光模式，否则 `S` 值不会调制激光。
  用 `$$` 检查 `$30`（最大 S）与 `$32` 两项。
- **床身范围**：先确认工件尺寸小于行程。脚本可用 `--bed W H` 自动检查刀路是否超床身。
- **夹具**：工件必须压紧/夹紧——移动中的工件会移位并撞坏喷嘴或反射激光。
- **清理**：焦油残渣会累积在透镜/防护镜上并烧毁镀膜，定期用无水乙醇+无尘纸清洁。

## 5. 交付话术（对用户一定要说）

1. “这些参数是**起点**，先在同批废料上做测试网格。”
2. “切割时开气泵、人别走开、旁边备好灭火手段。”
3. 材料对应的通风要求（MDF/皮革/亚克力/毛毡必须排烟）。
4. 机器 `$$` 里的 `$30`/`$32` 是否与本次生成一致。
5. 若脚本打印了 `[warn]`（越界、超床身、档位越界、宽高比），逐条转述，不要吞掉。
