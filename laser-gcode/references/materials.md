# 激光材料参数库

本文件是 `scripts/generate_gcode.py` 使用的材料数据库 `materials.json` 的人类可读说明。
脚本会自动读取 `materials.json`（启动时做 schema 校验，字段缺失或越界会直接报错），
无需手动编辑本文件即可运行——本文件用于理解参数含义、选材与安全须知。

快速查看有哪些材料与档位：

```bash
python3 scripts/generate_gcode.py --list-materials
```

## 参数如何换算

- **S 值**：GRBL 的激光强度指令，范围 `0` ~ `$30`（通常 `$30=1000`，先发 `$$` 确认）。
- **功率% → S**：`S = power_percent / 100 × grbl_max_s`。例如 40% 功率、`$30=1000` → `S400`。
- **额定功率（laser_w）**：激光模组的**光学输出功率**（W），不是电功率。
  - 5W / 10W / 20W / 40W 是常见二极管激光档位。
  - 同一材料在不同功率机器上所需**功率%**不同：低功率机器需更高百分比与更多遍数。
  - 真实光功率 = `S/$30 × laser_w`。`--check` 会直接把这个数算给你看。
- **进给速度 F**：单位 mm/min。`mm/s = mm/min ÷ 60`（LightBurn/Ruida 常用 mm/s）。

## 材料库结构

`materials.json` 中每个材料条目形如：

```json
"plywood_3mm": {
  "name": "Plywood / Basswood 3mm",
  "tiers": {
    "10": {"cut": {"power": 100, "feed": 500, "passes": 2},
           "engrave": {"power": 40, "feed": 5000, "passes": 1}}
  }
}
```

- `tiers` 按**激光功率档位**（W）组织，键必须是数字。
- 脚本选择**最接近且 ≥ `--laser-w`** 的档位；若 `--laser-w` 高于所有档位则取最高档，
  并打印 `[warn]` 提醒（此时实际光功率会高于表格意图）。
- `fill`（填充雕刻）默认复用 `engrave`；某个档位若自己写了 `fill` 块，则以 `fill` 块为准。
- `cut.passes=0` 表示该材料**不支持切割**（阳极氧化铝、板岩只能标记/雕刻）。

## 测试网格（强烈建议）

正式加工前花 5 分钟做一次参数矩阵，比事后返工便宜得多：

1. 在**同一批**废料上切一个 5×5 的方块矩阵。
2. 行 = 功率（例如材料推荐值 ±20%），列 = 速度（推荐值 ±30%）。
3. 选“刚好切透且边缘最不焦黑”的那格，作为后续的基准。
4. 记录焦距、气泵档位、材料批次——换批料参数可能就要改。

## ⚠️ 安全须知（务必遵守）

完整版见 `safety.md`，最小必读清单：

1. **所有参数均为起点**：批次、焦距、透镜、气泵、机器功率都会影响结果，先在废料上测试。
2. **二极管激光无法切割金属**；透明亚克力也不可切（光束直接穿透）。用深色浇铸亚克力。
3. **MDF、皮革、亚克力、毛毡、织物**加工时必须排烟通风——有害烟气。
4. **纸张/薄纸**极易引燃，用最低功率与最高速度，全程看护。
5. **气泵（air assist）**：切割时强烈建议开启，可减少烧焦与火焰。
6. **焦距**：每次换材料重新对焦，焦距偏差是参数失准的首要原因。
7. **禁止加工 PVC/乙烯基/ABS/聚碳酸酯/含铬皮革/未知塑料**——会释放剧毒气体。
8. **人不能离开**：激光加工是明火级别的火灾风险，旁边备好灭火手段。

## 添加新材料

在 `materials.json` 中新增一个 key，按功率档位填入 `cut`/`engrave` 参数即可；
建议同时写一个 `fill` 块（如果填充雕刻需要与描边雕刻不同的功率）。
填写后运行 `python3 scripts/generate_gcode.py --list-materials` 验证 schema：
字段缺失、功率越界、档位键非数字都会立刻报错。

建议参考实测测试网格的结果填入，而非照搬网络数值。
