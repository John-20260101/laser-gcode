# 完整案例：枫叶切割

本技能的标准用例，演示从顶点输入到 G 代码输出的全过程，
重点体现**坐标系翻转**与**材料档位换算**两个核心机制。SKILL.md 里是精简版，这里是完整版。

## 用户输入

一张枫叶轮廓图，22 个顶点（归一化 0–100 网格，原点在左上角、Y 向下），
10W 二极管激光切 3mm 椴木，目标 80mm 见方。

顶点（从顶部尖角顺时针）：

```
50,2 57,18 71,16 62,35 98,43 78,62 93,68 65,75 68,85 53,80 53,98 47,98 47,80 32,85 35,75 7,68 22,62 2,43 38,35 29,16 43,18 50,2
```

注意末尾的 `50,2` 与首个顶点相同——这是常见的“闭合轮廓”写法，脚本会自动识别并去掉重复的收尾点，
不会多出一条零长度移动。

## 运行命令

```bash
python3 scripts/generate_gcode.py \
  --vertices "50,2 57,18 71,16 62,35 98,43 78,62 93,68 65,75 68,85 53,80 53,98 47,98 47,80 32,85 35,75 7,68 22,62 2,43 38,35 29,16 43,18 50,2" \
  --job cut --material plywood_3mm --laser-w 10 --target-size 80 80 \
  --output maple_leaf_cut.gcode
```

## 输出参数

stderr 摘要（机器可读，可直接引用给用户）：

```
[summary] S=1000 feed=500 passes=2 polys=1 spans=0 bbox="X1.600..78.400 Y1.600..78.400 (76.80 x 76.80 mm)" burn=670.0mm est=1.4min
```

- 10W 机器切 3mm 椴木 → 材料库 10W 档：功率 100% → `S1000`，速度 `500 mm/min`，2 遍。
- 这就是「按功率档位换算」的价值：同一份参数库，40W 机器自动给
  `70% → S700`、`1500 mm/min`、1 遍（实际光功率 28W），无需用户记两套数字。
- 包围盒 `76.8 × 76.8 mm` 落在 80mm 见方内；预计耗时 1.4 分钟（含 2 遍）。

## 生成的 G 代码（节选）

```gcode
; Job: cut | Material: Plywood / Basswood 3mm | Laser: 10W (tier 10W)
; Power: 100% -> S1000/1000 | Feed: 500 mm/min | Passes: 2
; Target: 80x80 mm | Origin(out): bottom-left | Polygons: 1
; BBox: X1.600..78.400 Y1.600..78.400 (76.80 x 76.80 mm) | Burn: 670.0 mm | Est: 1.4 min
; WARNING: starting parameters - always test on scrap first.
G21
G90
G17
M5
; --- cut poly1 (S=1000, F=500, passes=2) ---
G0 X40.000 Y78.400      <- 顶部尖角：原图 (50,2) 缩放 0.8 得 X=40，Y 翻转后 78.4（叶尖朝上）
M3 S1000
G1 F500
G1 X45.600 Y65.600      <- (57,18) -> (45.6, 65.6)
G1 X56.800 Y67.200      <- (71,16) -> (56.8, 67.2)
G1 X49.600 Y52.000
G1 X78.400 Y45.600
... 沿全部顶点闭合，然后重复第 2 遍（每遍开始前 M5 关光、G0 回起点、M3 重新出光）...
M5
G0 X0.000 Y0.000        <- 收工回到工件原点（已关光）
M2
```

## 关键教学点

1. **Y 翻转**：原图顶部尖角在 `(50,2)`（Y=2 靠上），脚本翻转到 `Y=78.4`。
   GRBL/CNC 标准原点在左下、Y 向上；若不翻转，你会刻出**倒置的枫叶**。
   这是最易出错、也最容易被忽略的一步。
2. **闭合与去重**：脚本自动闭合并去掉重复的首/末点，不会输出零长度移动。
3. **每遍重新定位**：第 2 遍前 `M5 → G0 起点 → M3 S` 重新出光，
   这样开放路径（不闭合）也能正确多遍加工。
4. **安全提示**：交付时务必附上「参数是起点，先在废料测试；切割开气泵；椴木通风」。

## 换成 SVG 输入

同一个图形若已经是 SVG，直接用 `--svg` 即可，脚本会按 `viewBox` 自动换算尺寸：

```bash
python3 scripts/generate_gcode.py --svg maple_leaf.svg --job cut \
  --material plywood_3mm --laser-w 10 --target-size 80 80 -o maple_leaf_cut.gcode
```

若 SVG 的 `viewBox` 是 `0 0 100 100`，输出与上面逐点一致；
若是 `0 0 1000 1000` 之类的大坐标系，也会被正确缩放到 80mm（不会放大 10 倍）。
