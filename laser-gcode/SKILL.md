# 激光图形转 G 代码

把平面图形变成可上机运行的 GRBL 激光 G 代码，并给出匹配材料与机器的功率/速度参数。

## 何时使用

凡是涉及「激光雕刻/切割」「图形转 G 代码」「激光功率速度」「在 X 材料上激光加工」的需求都应触发本 skill。典型信号：用户贴了一张轮廓图、给了 SVG、列了一串坐标点、或问"这个图形要多少功率多快速度"。

## 核心设计思想（理解这点很重要）

激光功率指令 `S` 是 **0–1000 的 PWM 占空比**（`$30=1000` 时），不是真实光功率。真实光功率 = `S/1000 × 激光器额定功率`。因此：

- **同一材料在不同功率机器上需要的 `S` 值不同**。10W 机器切 3mm 木板要 `S1000`（满功率），40W 机器只需 `S700`。
- 本 skill 的材料库按**激光器功率档位**（5/10/20/40W）存储「功率% + 速度 + 遍数」，再根据用户填的额定功率选档并换算出正确的 `S`。这让同一份材料库可在 10W 和 40W 机器上通用——这是本 skill 的核心价值，务必保留这个换算逻辑。

## 工作流程

### 第 1 步：收集输入

向用户询问以下信息。括号内为合理默认值，用户未给就用默认，但**额定功率和材料**最好确认：

| 输入 | 说明 | 默认 |
|---|---|---|
| **图形** | 顶点坐标列表（归一化 0–100）或 SVG 文件路径 | 必填 |
| **作业类型** | `cut`（切割）/ `engrave`（轮廓雕刻）/ `fill`（内部填充扫描） | `cut` |
| **材料** | 见 `references/materials.json` 的 key，如 `plywood_3mm` | `plywood_3mm` |
| **激光器额定功率** | 光学输出功率 W（5/10/20/40…） | 10 |
| **目标尺寸** | 最终加工尺寸 mm `[宽, 高]` | `[100, 100]` |
| **输入坐标原点** | 顶点坐标的 Y 方向：`top-left`（图像/屏幕坐标，Y 向下）或 `bottom-left` | `top-left` |
| **输出原点** | 机床坐标系：`bottom-left`（标准 CNC，Y 向上）或 `top-left` | `bottom-left` |
| **$30 最大 S** | GRBL `$30` 参数 | 1000 |
| **覆盖项（可选）** | `power`（功率%）、`feed`（mm/min）、`passes`、`hatch_spacing`、`hatch_angle` | 用材料库推荐值 |

**坐标系处理**：大多数图形/图像坐标原点在左上角、Y 向下；而 GRBL/CNC 标准原点在左下角、Y 向上。脚本会自动翻转 Y 轴，让图形方向正确（叶尖朝上）。如果用户的机床用左上角原点，把 `--output-origin` 设为 `top-left` 即可跳过翻转。理解这一点能避免雕刻出镜像/倒置图形。

### 第 2 步：运行生成脚本

本 skill 自带 `scripts/generate_gcode.py`，它封装了坐标变换、材料参数换算、填充扫描算法——**优先用它**，不要每次手写 G 代码。脚本是确定性的，能保证输出一致且正确。

```bash
python3 scripts/generate_gcode.py \
  --vertices "50,2 57,18 71,16 ..." \
  --job cut \
  --material plywood_3mm \
  --laser-w 10 \
  --target-size 80 80 \
  --output /path/to/output.gcode
```

顶点格式很灵活：`"50,2 57,18 ..."`、`"50 2;57 18"`、或 JSON 数组 `[[50,2],[57,18]]` 都行。

SVG 输入用 `--svg path/to/file.svg`，支持 `<polygon>`/`<polyline>`/`<rect>`/`<path>`（M/L/H/V/C/Q/Z，贝塞尔会自动展平为折线）。

也可用 JSON 配置文件 `--config job.json` 一次性传所有参数（键名用下划线，如 `laser_w`、`target_size`、`hatch_spacing`），优先级高于命令行。

**填充扫描**：`--job fill` 会用 boustrophedon（牛耕式）扫描线填充闭合多边形内部，`--hatch-spacing`（默认 0.2mm）控制线距，`--hatch-angle` 控制扫描方向。间距越小越密但越慢；木材雕刻常用 0.1–0.3mm。

### 第 3 步：输出

脚本会生成 `.gcode` 文件，并在 stderr 打印一行 `[summary] S=... feed=... passes=...`。向用户交付时请包含：

1. **G 代码文件路径**
2. **参数摘要**：材料、额定功率、选用的功率档位、换算后的 `S` 值、进给速度、遍数、目标尺寸
3. **安全提示**：参数是起点，务必先在废料上做小测试；切割用气泵；MDF/皮革/亚克力需通风。这些不是客套——激光参数失准会烧穿或引燃材料，提醒能避免事故。

## 完整案例：枫叶切割（参照此例理解整个流程）

这是本 skill 的标准用例，展示了从顶点输入到 G 代码输出的全过程，重点体现**坐标系翻转**与**材料档位换算**两个核心机制。

**用户输入**：一张枫叶轮廓图，22 个顶点（归一化 0–100 网格，原点在左上角、Y 向下），10W 二极管激光切 3mm 椴木，80mm 见方。

顶点（从顶部尖角顺时针）：
```
50,2 57,18 71,16 62,35 98,43 78,62 93,68 65,75 68,85 53,80 53,98 47,98 47,80 32,85 35,75 7,68 22,62 2,43 38,35 29,16 43,18 50,2
```

**运行命令**：
```bash
python3 scripts/generate_gcode.py \
  --vertices "50,2 57,18 71,16 62,35 98,43 78,62 93,68 65,75 68,85 53,80 53,98 47,98 47,80 32,85 35,75 7,68 22,62 2,43 38,35 29,16 43,18 50,2" \
  --job cut --material plywood_3mm --laser-w 10 --target-size 80 80 \
  --output maple_leaf_cut.gcode
```

**输出参数**（脚本 stderr 摘要）：`S=1000 feed=500 passes=2`
- 10W 机器切 3mm 椴木 → 选用材料库 10W 档：功率 100% → `S1000`，速度 `500 mm/min`，2 遍。
- 这就是「按功率档位换算」的价值：同样的椴木，40W 机器会自动给 `S700/feed1500/1遍`，无需用户记参数。

**生成 G 代码片段**（注意 Y 轴已翻转）：
```
; Job: cut | Material: Plywood / Basswood 3mm | Laser: 10.0W (tier 10W)
; Power: 100.0% -> S1000/1000 | Feed: 500.0 mm/min | Passes: 2
; Target: 80.0x80.0 mm | Origin(out): bottom-left | Polygons: 1
G21
G90
G17
M5
; --- cut poly1 (S=1000, F=500.0, passes=2) ---
G0 X40.000 Y78.400      <- 顶部尖角：原图 (50,2) 缩放 0.8 后 X=40，Y 翻转后=78.4（叶尖朝上）
M3 S1000
G1 F500.0
G1 X45.600 Y65.600       <- (57,18) -> (45.6, 65.6)
G1 X56.800 Y67.200       <- (71,16) -> (56.8, 67.2)
... (沿 22 个顶点闭合，重复 2 遍) ...
M5
M2
```

**关键教学点**：
1. **Y 翻转**：原图顶部尖角在 `(50,2)`（Y=2 靠上），脚本翻转到 `Y=78.4`（靠上但在 CNC 坐标里是大值）。若不翻转，直接用 `(40, 1.6)` 会在标准 GRBL 机器上刻出**倒置的枫叶**。这是最易出错、skill 自动处理的关键点。
2. **闭合**：脚自动在每遍末尾返回起点闭合多边形，无需用户重复首点。
3. **安全提示**：交付时务必附上「参数是起点，先在废料测试；切割开气泵；椴木通风」。

## G 代码结构（脚本已自动生成，了解即可）

```
G21          ; 毫米
G90          ; 绝对坐标
G17          ; XY 平面
M5           ; 确保激光关闭
G0 X.. Y..   ; 快速定位到起点
M3 S<功率>    ; 开启激光
G1 F<速度>    ; 设进给
G1 X.. Y..   ; 沿轮廓/扫描线加工
... 
M5           ; 关闭激光
M2           ; 结束
```

## 材料参数库

详见 `references/materials.md`（人类可读说明）与 `references/materials.json`（脚本数据源）。
材料库的数值是**起点**，受批次/焦距/气泵影响，必须实测微调。添加新材料只需在 `materials.json` 加一个 key 并按功率档位填参数。

## 重要边界与失败处理

- 顶点 < 3 个：脚本会报错，提示用户补全图形。
- 材料不支持切割（如阳极氧化铝 `passes=0`）：脚本会报错，应改用 `--job engrave`。
- 二极管激光**不能切金属、不能切透明亚克力**——遇到这类需求要明确告知用户限制，不要硬生成会失败的 G 代码。
- SVG 解析不到图形：提示用户检查 SVG 是否含 `polygon`/`path` 等元素。
- 用户给了图片而非坐标/SVG：请用户描述轮廓顶点（像枫叶案例那样给出归一化坐标），或提供 SVG。

## 与用户的沟通

- 参数术语（S、F、$30、PWM）对新手可能陌生，必要时简短解释：`S` 是激光强度档位（0–1000），`F` 是移动速度（毫米/分钟）。
- 给出参数时同时说明**为什么**选这个值（如"3mm 椴木在 10W 机器上需满功率切两遍"），帮助用户理解而非盲从。
- 鼓励用户先做小测试网格再正式加工——这是激光加工的标准做法，能省下大量返工。
