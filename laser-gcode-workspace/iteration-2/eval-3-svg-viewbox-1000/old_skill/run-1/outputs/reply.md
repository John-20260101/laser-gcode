# 50mm 正方形切割 G 代码（10W 二极管 / 3mm 椴木）

## 一、先说一个必须提醒你的坑（不然这一刀会撞机）

你这份 SVG 的 `viewBox` 是 `0 0 1000 1000`，里面的矩形是按 **1000 用户单位**画的（`<rect width="1000" height="1000">`）；
而 G 代码生成脚本按**归一化 0–100 网格**来解释坐标，并且**不读 viewBox**。
所以如果直接把原文件丢进去并告诉它"目标 50mm"，它会算成 1000/100 × 50 = **500mm**，我实测了一下：

```
G0 X0.000 Y50.000
G1 X500.000 Y50.000
G1 X500.000 Y-450.000     ← 负坐标，500mm 行程
```

这已经远超你的 100×100 床身，直接跑会撞限位、甚至撞坏机器。**所以我先把 SVG 归一化到 0–100 单位（整体除以 10）再生成**，
这样"整张画布 = 100 单位"，目标尺寸设成 50 就得到正好 50mm 的正方形。归一化后的文件我一并存了：
`square_50mm_normalized.svg`（内容和你的原图完全等比例，只是单位从 1000 缩到 100）。

另外我也用一个 0–100 的顶点方框做了一次交叉校验，两条路径生成的 G 代码**逐字节相同**，说明尺寸与形状都没问题。

## 二、交付的 G 代码

**文件：`square_50mm_cut.gcode`**

```gcode
; Job: cut | Material: Plywood / Basswood 3mm | Laser: 10.0W (tier 10W)
; Power: 100.0% -> S1000/1000 | Feed: 500.0 mm/min | Passes: 2
; Target: 50.0x50.0 mm | Origin(out): bottom-left | Polygons: 1
; WARNING: starting parameters - always test on scrap first.
G21
G90
G17
M5
; --- cut poly1 (S=1000, F=500.0, passes=2) ---
G0 X0.000 Y50.000
M3 S1000
G1 F500.0
G1 X50.000 Y50.000
G1 X50.000 Y0.000
G1 X0.000 Y0.000
G1 X0.000 Y50.000
G1 X0.000 Y50.000
G1 X50.000 Y50.000
G1 X50.000 Y0.000
G1 X0.000 Y0.000
G1 X0.000 Y50.000
G1 X0.000 Y50.000
M5
M5
G0 X0 Y0
M2
```

说明几个细节：

- **正方形落在机床 (0,0)–(50,50)**：正好 50×50mm，安全地待在你 100×100 的床身内，左下方角贴机床原点。切割路径里有 `G0 X0 Y0` 的结束回零，正常。
- **Y 轴已经翻转**：脚本按「输入左上角原点 → 输出左下角标准 CNC 原点」做了翻转。正方形翻不翻都一样，所以这次不用纠结；以后切枫叶那类不对称图形，这一步就是关键。
- **`M5` 出现两次**是脚本的正常输出（一遍结束关光、作业收尾再关一次），不是重复切割。
- **切了两遍（2 passes）**，不是写错了——3mm 椴木在 10W 上单遍通常切不透。

## 三、参数摘要与选值理由

| 项目 | 取值 | 为什么 |
|---|---|---|
| 材料 | `plywood_3mm`（椴木/桦木板 3mm） | 你给的是 3mm 椴木 |
| 激光额定功率 | 10W → 命中材料库 **10W 档** | 材料库按功率档位存参数，10W 正好落在 10W 档 |
| 功率 | 100% → **S1000**（`$30=1000`） | 3mm 椴木对 10W 二极管属于"满功率活"，功率留不出余量 |
| 进给 F | **500 mm/min**（≈8.3 mm/s） | 10W 档位推荐值；太快切不透，太慢会烧焦发黑 |
| 遍数 | **2 遍** | 单遍功率再高也常常留一丝粘连，两遍是这套参数的稳妥解 |
| 目标尺寸 | **50 × 50 mm** | 你要的 50mm 正方形 |
| 坐标原点 | 输入 top-left → 输出 bottom-left（标准 GRBL） | 默认约定 |

顺带说一下"按功率档换算"的价值：同样是 3mm 椴木，换到 40W 机器上，本套参数会自动变成 **S700 / F1500 / 1 遍**（我实测跑过档位换算，确实如此）——所以你不用记死数，换机器时只改功率就行。

## 四、上机前的安全与检查清单（请务必过一遍）

1. **参数只是起点**：先拿废料切一个小方块（或用同一份 G 代码切 10mm 的小测试块）验证，再切正式件。批次、焦距、气泵、透镜都会影响结果。若切不透 → 降速或加一遍；若边缘严重焦黑/起火 → 升速或降一点 S。
2. **确认你的 `$30`**：这份代码假设 `$30=1000`。你的机器若是 `$255` 之类，S1000 会被截顶，必须重算（告诉我 `$30` 我改，或用 `--grbl-max-s` 重生成）。
3. **开气泵（air assist）**：切木板强烈建议开，能明显减少烧焦和明火。
4. **通风**：椴木/胶合板夹胶燃烧有烟，注意排烟与看护，别离开机器。
5. **对焦**：换材料重新对焦，焦距偏差是参数失准的头号原因。
6. **戴护目镜**，并确认机器外壳/滤光罩到位。
7. **如果你机器原点在左上角**（Y 向下），要把输出原点改成 top-left 重新生成，否则图形会上下颠倒。
8. **如果想让它摆在工作台中间**，不要改代码里任何东西，加偏移重新生成即可（例如 100×100 床身居中就是偏移 25,25）。
