## 3. 尺寸校验（解析生成的 G 代码，量 X/Y 跨度）

```
python3 - <<'PY'
import re
p="/Users/johnsmacbook/Desktop/Program/deepseek/laser-gcode-workspace/ab/out/p3-old/square_50mm_cut.gcode"
xs=[];ys=[]
for l in open(p):
    m=re.match(r"G[01] X([-\d.]+) Y([-\d.]+)",l)
    if m: xs.append(float(m.group(1))); ys.append(float(m.group(2)))
print("X range",min(xs),max(xs),"width",max(xs)-min(xs))
print("Y range",min(ys),max(ys),"height",max(ys)-min(ys))
PY
```

stdout:

```
X range 0.0 50.0 width 50.0
Y range 0.0 50.0 height 50.0
```
