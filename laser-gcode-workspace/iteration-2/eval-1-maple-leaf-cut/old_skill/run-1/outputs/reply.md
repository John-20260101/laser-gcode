# 枫叶切割 G 代码（10W 二极管激光 / 3mm 椴木板 / 80×80mm）

已经按你给的 22 个顶点生成好可以直接上机的 G 代码了。下面是文件和参数，以及为什么要选这些值。

## 一、文件

## 二、参数摘要（你要的"多少功率、多少速度"）

| 项目 | 值 |
|---|---|
| 材料 | 椴木/胶合板 3mm（`plywood_3mm`） |
| 激光器额定功率 | 10W |
| 选用的功率档位 | **10W 档** |
| 功率百分比 | 100% |
| **S 值（功率指令）** | **S1000**（$30=1000 时的满功率） |
| **进给速度 F** | **500 mm/min** |
| **遍数** | **2 遍** |
| 目标尺寸 | 80 × 80 mm（轮廓包围盒，原图归一化 0–100 等比缩放） |
| 输出原点 | 左下角（GRBL/CNC 标准），Y 轴向上 |

**为什么是这几个数**：3mm 椴木在 10W 二极管上属于"临界厚度"——单遍切不透，所以给满功率 S1000 配 500mm/min、走 2 遍。慢速+满功率+两遍是为了让切缝真正透底而不是切出一圈焦黑。如果你后来换了 40W 机器，同一块板子会自动变成 S700 / 1500mm/min / 1 遍，不用你重新记参数。

注意：`S` 是激光强度档位（0–1000 的 PWM 占空比），不是真实光功率。真实光功率 = S/1000 × 额定功率，所以 S1000 在 10W 机器上就是约 10W 输出。`F` 是移动速度，单位毫米/分钟。

## 三、坐标系说明（重要，别跳过）

- 你的顶点是**图像坐标**（原点在左上角、Y 向下），我在生成时已经**翻转了 Y 轴**，输出到机床标准的**左下角原点**。
- 验证一下：原图顶部尖角 `(50,2)` → 缩放 0.8 后是 `(40, 1.6)` → 翻转后为 `X40.000 Y78.400`，在 G 代码第 10 行。**叶尖朝上**是对的。
- 如果你直接用 `(40, 1.6)` 不翻转，机器上刻出来的会是**倒置的枫叶**——这是这类转换最容易翻车的地方。
- 如果你的机器原点确实设在左上角，就在命令里加 `--output-origin top-left` 让它跳过翻转。
- 图形已在 0–80mm 内，左下角对齐到 `(0,0)` 附近（X 范围 1.6–78.4，Y 范围 1.6–78.4）。G 代码结尾 `G0 X0 Y0` 会把激光头移回原点，方便取件。
- 这 22 个点首尾点相同（都是 `50,2`），脚本已按闭合多边形处理，每遍末尾自动返回起点闭合，你不会看到缺口。

## 四、上机前必做的安全事项

1. **先在废料上试**：参数是材料库给的起点，实际受板材批次、密度、焦距、气泵影响很大，先拿同批椴木边角料按同样 S/F 跑一遍，看是否切透、背面是否过烧，再动正式件。激光参数失准轻则烧穿、重则引燃材料。
2. **切割必须开气泵（air assist）**：吹走烟尘和熔渣，能显著提高切透率、减少焦边，也是防火的必要措施。
3. **通风**：椴木/胶合板的胶层和烟尘有害，务必在通风处或接排烟；不要把机器放在无人看管的地方运行。
4. **调焦**：确保镜片聚焦到板材表面（或用 2mm 垫片法），焦点偏了上面这些参数就不成立。
5. **建议先做参数测试网格**：在边角料上切几组（比如 S1000/F500/2遍、S1000/F400/2遍、S1000/F500/3遍），挑出"刚好切透且背面干净"的那组，正式加工就用它。这一步能省下大量返工。
6. 二极管激光不能切金属、也不能切透明亚克力——如果你以后想换材料，注意这个限制。

## 五、想要别的效果的话

- **只想在木板上刻出叶子轮廓（不切透）**：把 `--job cut` 换成 `--job engrave`，10W 档会给 S400 / 5000mm/min / 1 遍（40% 功率浅刻轮廓）。
- **想刻一个实心的深色叶子**：用 `--job fill` 做内部填充扫描，`--hatch-spacing` 控制线距（默认 0.2mm，木材常用 0.1–0.3mm），`--hatch-angle` 控制扫描方向。
- **尺寸要改**：`--target-size 100 100` 之类改整体尺寸即可，坐标会自动等比缩放。
- **你的机器 $30 不是 1000**（比如设成了 255）：把 `--grbl-max-s 255` 传进去，S 值会自动按占空比重新换算。
