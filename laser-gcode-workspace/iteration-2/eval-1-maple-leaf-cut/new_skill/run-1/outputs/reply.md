**为什么是这个数**：`S` 不是光功率，而是激光强度档位（0–1000，上限由机床 `$30` 决定）。真实光功率 = `S / $30 × 额定功率`，所以 `S1000` 在你 10W 机器上就是 10W 满功率输出。同一张 3mm 椴木，换成 40W 机器，材料库会给出 70% → `S700`、1500 mm/min、1 遍（实际光功率约 28W）——不是机器越猛就越快，而是同一份参数表自动适配不同机器。

## 四、上机前请确认这 4 件事

1. **打开激光模式**：发 `$$` 看两项——`$30` 应为 `1000`（和本次生成的 `S1000` 一致），`$32` 应为 `1`。`$32=0` 时 `S` 值不会调制激光，会完全不出光或全功率乱烧。
2. **重新对焦**：椴木 3mm 的焦点必须对准板面。焦距偏差是「参数看着对、实际切不透」的头号原因。
3. **开气泵**：切割必须开，能明显减少焦边和火焰。
4. **参数只是起点**：椴木胶水含量批次差异很大。请在**同一批废料**上先切一个 5×5 的测试网格（行 = 功率 80%–120%，列 = 速度 350–650 mm/min），挑「刚好切透、边缘最不焦黑」的那一格，再改 `--power` / `--feed` / `--passes` 重新生成。**不要手工改我给你的 G 代码**，改参数重跑脚本更安全。

## 五、安全红线（椴木也一样要守）

1. **人不能离开机器**：激光加工是明火级别的火灾风险，火焰常常从工件背面起来，正面看不出来。旁边备好灭火器/湿毛巾，知道电源开关在哪。**不要把工件直接垫在木板或纸板上**，用蜂窝板或金属垫板。
2. **护目镜 + 外罩，不要直视光斑**（包括工件反射的散射光）。445nm 蓝光要戴对应防护镜，普通墨镜反而更危险。
3. **排烟通风**：胶合板含胶，烟大，请排到室外，不是「开个窗」。**禁止加工** PVC/乙烯基/仿皮、ABS、聚碳酸酯、玻纤/碳纤维、含铬鞣制皮革、任何未知塑料——会释放氯气、氰化物、六价铬等剧毒气体。
4. **夹具压紧**：移动中的工件会移位，撞坏喷嘴或反射激光。
5. 切完继续观察 1–2 分钟，暗火可能停机后才冒烟。
