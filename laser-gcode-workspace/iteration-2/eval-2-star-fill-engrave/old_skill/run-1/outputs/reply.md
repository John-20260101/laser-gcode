# 五角星 logo 填充雕刻 G 代码（20W 二极管 / 深色亚克力 / 50mm 见方）

## 一、先回答你最担心的问题：会，而且你担心得对

**直接回答：会烧到。** 按最朴素的做法（直接让软件做内部填充扫描），激光在星形凹口之间确实是**不关光横穿**的，那几处"角与角之间的空隙"会被划上一排横向的烧痕。

我逐行核对了生成出来的 G 代码，实测数据是这样的：

- 50mm 的星形一共 210 条水平扫描线，其中 **28 行**在穿过星形时会"断开"成 2～3 段（因为中间是空的）；
- 填充脚本在断开的两段之间是用 `G1`（**激光仍然开着 `M3`**）连过去的，于是这些行在空隙里拉出直线：共 **56 段，累计 389mm，最长的一条 13.1mm**；
- 这些线占了全部烧灼长度的 **8.5%**——也就是说这条路径把 8.5% 的激光能量浪费在了不该烧的地方；
- 位置很集中：只出现在 **Y=10.2～12.8mm** 和 **Y=36.2～38.8mm** 两条 2.6mm 宽的窄带里，也就是**上下两个尖角与相邻尖角之间的 4 个凹口**。左右两个尖角附近的凹口没事——因为扫描线是水平的，只会"并排"穿过上下尖角附近的角臂，左右两侧的角臂是上下排列的，水平线不会横穿过去。

**视觉后果要说准确**：空隙里每 0.2mm 才有一条线，烧灼密度大约只有星形内部的 **2%**，所以**不会**被烧成整片实心黑块、星形也不会"糊成一坨"；但那 4 个凹口会留下**明显的横向条纹鬼影**（尤其深色亚克力雕刻后是发白的磨砂面，白色条纹在黑底上很显眼）。一句话：**不是烧黑，是"划花"**——照样得修。

**已经修好了。** 我把 58 处段间连线改成了 `M5`（关光）→ `G0`（空走）→ `M3 S350`（重新开光），几何、S 值、速度、填充方式一律不动。修改后实测：

| | 脚本原样输出 | 修复后（推荐上机） |
|---|---|---|
| 落在星形**内部**的烧灼长度 | 4195 mm | 4195 mm（正好 = 面积 839mm² ÷ 线距 0.2mm，说明每 1mm 都烧在星形里） |
| 落在星形**外部**（横穿空隙）的烧灼长度 | **389 mm** | **0 mm** |
| 预计加工时间（净加工） | 约 72 s | 约 74 s |

（时间按 `烧灼长度 ÷ 4000` + `空走长度 ÷ 3000` 估算，是理论下限；机器有加减速，实际大概 2～3 分钟。）

也就是说：**修这个只多花 2 秒，但能救回整个 logo**。

> 你打开 `preview_gap_check.svg`（浏览器直接拖进去）能一眼看到差别：左边 A 是脚本原样，**红色线**就是激光开着横穿空隙的那些线；右边 B 是修复后，红色完全没有了。

这也说明一件事：真正的激光软件（LightBurn 之类）做填充时，段与段之间的"空走/穿行"默认都是**关光快速移动**的。你这个担心不是多虑，是行业里的标准注意点。

## 三、参数（20W 机器 / 深色亚克力）

| 项目 | 值 | 说明 |
|---|---|---|
| 材料 | 深色/浇铸亚克力（参数库按 3mm 标定） | 深色亚克力吸光好，二极管可以雕刻；**透明亚克力不行** |
| 激光器额定功率 | 20W | 参数库自动选了 **20W 档** |
| 功率 | **35% → `S350`**（按 `$30=1000`） | 换算成真实光功率约 **7W**。20W 机器不需要满功率，满功率会把亚克力烧化发黄 |
| 进给速度 | **`F4000`**（mm/min） | 20W 档推荐值 |
| 遍数 | **1** | 填充扫描本身只走一遍，靠 0.2mm 线距覆盖成面 |
| 填充线距 | **0.2 mm** | 210 条扫描线 |
| 填充方向 | **0°（水平）**，牛耕式往复 | |
| 目标尺寸 | **50 × 50 mm** 画布 | 原点在画布左下角，取值域 X 0～50、Y 0～50 |
| 坐标原点 | 输出为 GRBL 标准（**左下角，Y 向上**） | 图形已自动做 Y 翻转，星尖朝上，不会刻成倒的 |

**为什么是这些值**：`S` 不是真实功率，是 0–1000 的 PWM 档位（`S350`＝35% 占空比），真实光功率 ≈ 35% × 20W ≈ 7W。深色亚克力对这种功率的吸收很好，35% 正好吃出一层均匀的磨砂白；速度给到 4000mm/min 是为了避免局部过热起泡发黄。填充不吃"遍数"，想更深请改功率/速度/线距，而不是加遍数。

## 四、尺寸要注意一个细节

你给的 SVG 画布是 100×100，但**星形本身只占其中的 88×84**（四周有留白）。所以按"50mm 见方"（画布 50×50）生成后：

- **星形实体尺寸 = 44 × 42 mm**，位于 X 3～47、Y 4～46，四周各留 3～4mm 空白。
- 如果你要的是**星形本体正好 50mm 宽**，把画布放大即可（星形会变成 50×47.7mm）：把参数改成 `--target-size 56.8 56.8` 重新生成就行，跟我说一声我直接给你出新文件。

## 五、上机前请确认这 4 件事

1. **`$30` 是多少？** 我按 `$30=1000` 算的 `S350`。如果你的固件是 `$30=255`（部分老机器），`S` 要按比例换算（约 `S89`），否则功率差 4 倍。发我 `$$` 的输出我帮你换算。
2. **`$32=1`（激光模式）** 建议打开——这样 `G0` 空走时固件会自动关闭激光，和我在文件里显式加的 `M5` 形成双保险（即使 `$32=0`，这份文件也安全）。
3. **工件零点是否在左下角**、图形朝向是否和你的装夹一致。我按 GRBL 标准（原点左下、Y 向上）生成；如果你机器是左上角原点，我用 `--output-origin top-left` 重新出一份。
4. **对焦**：焦点落在亚克力表面（或略高 1～2mm）。填充想更"面"、线条更宽，可以离焦 2～3mm，但要同时把线距加到 0.3mm。

## 六、强烈建议先做一块废料测试（真的能省返工）

切 3×3 个小方块：功率 `S250 / S350 / S450` × 速度 `F3000 / F4000 / F5000`，一眼就能看出哪个组合是最干净的磨砂白、哪个开始发黄熔边。亚克力对功率过冲特别敏感，**先在边角料上定标，再上成品**。

## 七、想更好看的话（可选）

- **填充有横向条纹感**：把线距降到 `0.15` 或 `0.1`（时间成正比增加，0.1mm 约 2 倍多时间）。命令：把 `--hatch-spacing 0.1` 加上重跑。
- **表面更均匀的"绒面"**：先跑一遍 0° 填充，再跑一遍 `--hatch-angle 45` 叠上去（两次交叉），条纹感基本消失。需要的话我一起生成。
- **边缘更锐利**：先跑 `star_logo_fill_no_cross.gcode`，再跑一遍 `star_logo_outline.gcode`（同参数描边），轮廓线会很清楚。

## 八、另外提一句：这个 SVG 其实是"八角星"

顺手核对了图形：`star_logo.svg` 里是一条 **16 个顶点的闭合路径**，也就是**8 个角的星形**（外半径约 45.6、内半径约 22.8，角比较粗、凹口是浅 V 形），并不是传统 5 角星。如果你本意是五角星，可能是文件拿错了——把正确的 SVG 发我，我按同一套流程重跑（五角星只有 10 个顶点，凹口更深更尖，上面那个"横穿空隙"的问题会更明显、更值得按修复版走）。

## 九、安全提示

- **先废料试打**：以上参数是可靠起点，但受材料批次、焦距、气泵影响，必须实测微调。
- **必须开气泵**：亚克力雕刻不开气泵会熔边、发黄、发粘，甚至把熔融物甩到镜片上。
- **必须通风排烟**：亚克力气味大且有刺激性，请接排风，别在密闭房间长时间跑。
- **别无人看管**：深色材料吸光、局部升温快，起火风险始终存在，旁边备好灭火手段。
- 本次是**填充雕刻**（表层磨砂），不是切穿；深色亚克力可以雕，但二极管激光**不能切透明亚克力、不能切金属**——如果你后续要切穿这个形状，材料要换（比如深色亚克力用 20W 档：`S1000 / F600 / 2 遍`）。
