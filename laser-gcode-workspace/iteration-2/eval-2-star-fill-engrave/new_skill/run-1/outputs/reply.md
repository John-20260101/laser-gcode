# 星形 logo 填充雕刻：G 代码 + 参数（20W 二极管 / 深色亚克力 3mm）

## 0. 先回答你最担心的问题：不会横穿

**不会。** 角与角之间的空隙（凹口）不会被激光扫过去烧黑——这是这套 G 代码的走位方式决定的，不是靠运气。

填充扫描的**每一段燃烧线都是独立开关光**的，节奏是：

```
M5                 ← 先关光
G0 X25.067 Y1.236  ← 关着光快速移动到这一行的起点
M3 S350            ← 到这里才开光
G1 X24.933 Y1.236  ← 只烧这一段
M5                 ← 立刻关光，下一段重复
```

本次文件里一共 **614 次开光（M3）** 对应 **613 条扫描线 + 1 圈轮廓**，每次开光前都先关光快移。也就是说：激光只在"星形内部"那几段上亮着，从一个内部片段跳到下一个片段时是**关着光**飞过去的，而凹口区域根本不在任何一段的起止点之间。

我做完 G 代码还做了几何复核（把每条出光走位按 41 个采样点回代进星形多边形，坐标系按脚本的缩放/平移/Y 翻转一致还原）：

- 出光走位 630 段，S 值全部是 350（没有任何一段是别的功率）；
- **落在星形之外超过 0.05mm 的出光点：0 个**；
- 星形实心面积约 **1083 mm²**，而外接矩形是 50 × 47.73 = 2386 mm²——**约 1300 mm²（55%）是星形以外的空白，全部不烧**。

### 但有两件事要有心理准备（这是物理，不是走位问题）

1. **边缘热影响圈**：激光光斑有直径（20W 二极管通常 0.08–0.15mm），加上热扩散，出光区域外侧 **0.1–0.2mm** 会有一圈轻微发白/浅焦。这是正常的边界效应，不会"横穿"整个空隙。
2. **扫描线两端会略深一点点**：每行扫描线的起止点（尤其星尖和谷底附近）是短走位，最短短到 0.13mm，全图 < 0.5mm 的走位有 11 条、< 1mm 的有 28 条。用 `M3` 恒功率时，机器在这些极短段上还没加速完就已经走完，单位长度能量偏高，所以**星尖/谷底会有一点点加深**，看着像"描了个边"。
   - 想让端点更干净：把 GRBL 的 `$32=1` 打开后用动态功率模式重新生成（加 `--laser-mode m4`，功率随进给自动降，减速段不过烧）。
   - 或者整体再降一点功率（`--power 30`）多刻一遍。

### 顺带一个发现：这个 SVG 其实是 8 角星，不是五角星

`star_logo.svg` 的路径有 16 个顶点，是 **8 个星尖 + 8 个谷底**（上、下、左、右 + 四个斜角），我把它栅格化确认过了。文件名叫 star_logo、你叫它五角星，但几何确实是八角星芒。本次加工不受影响（脚本按真实几何处理，8 个空隙一个都不会被烧）。如果你要的是标准五角星，把正确的 SVG/顶点发我，我重新出一版。

**为什么是这个功率**：参数库里 20W 档的亚克力雕刻基准是「35% 功率 + 4000 mm/min + 1 遍」，填充默认复用这一档。这个能量密度**离切穿差得很远**（同一材料 3mm 切穿要 100% 功率、600 mm/min、2 遍），所以只要不手动改参数，绝不会误切穿——你只是把表层刻白/雾化。

**关于"填满"的成色预期（重要）**：深色亚克力配蓝色二极管激光，刻出来通常是**发白/雾化的磨砂质感，不是更黑**（激光是把深色表层打毛/发泡）。如果你要的是"黑底上的亮星"，那这个方向对；如果你想要"更黑的实心块"，那用激光是反效果，那个得用白色亚克力或别的方式。先看废料上的实测效果最稳。

## 3. 尺寸口径（"50mm 见方"的两种理解）

SVG 的 viewBox 是 100×100，但星形本身的几何包围盒是 **88 × 84**（不是正方形），所以"50mm 见方"有两种落法，我选了能保住星形比例的那个：

| 口径 | 命令要点 | 星形实际尺寸 | 耗时 |
|---|---|---|---|
| ✅ **本次交付**：星形最大跨度 50mm，比例不变 | `--normalize auto --fit contain --target-size 50 50` | **50.00 × 47.73 mm** | 3.2 min |
| 工件画面框 50×50、星形按 SVG 原边距内缩 | `--frame 0 0 100 100 --target-size 50 50` | 44.00 × 42.00 mm | 2.5 min |
| 硬塞进 50×50（会拉伸变形 6%） | `--normalize auto --target-size 50 50`（默认 stretch） | 50.00 × 50.00 mm | 1.7 min |

第三种脚本会给一条 `[warn]`（"X 和 Y 缩放不一致，圆会变椭圆"），所以我**没有**用它——星形会被拉高 6%，肉眼能看出比例不对。要换算成 50×50 的实物框，第一种放在 50mm² 的亚克力方料上完全合适。

另外提醒：星形最左尖落在机床坐标 **X=0** 上（包围盒 X 0.000..50.000）。**加工时工件边缘不要正好压在对刀零点上**，建议四周留 5mm 以上余量；需要的话我给这版加个偏移（`--offset 5 5`）重新生成。

## 4. 上机步骤

1. **先确认机器两项设置**：发 `$$` 看到 `$30=1000`（S 的上限，本文件按 1000 生成）与 `$32=1`（激光模式，没开的话 S 值不会调制激光，会出现"完全不出光"）。
2. 工件**夹紧压平**，深色亚克力别用翘边料；底部用金属/蜂窝垫板，别直接垫木板纸板。
3. **重新对焦**（每次换材料/换高度都要做，焦距偏差是参数失准的第一原因）——填充雕刻对焦在**表面**。
4. 开**气泵**（雕刻开小风即可，能明显减少焦边和复燃）。
5. **先在同批废料上做测试网格**：5×5 的功率×速度矩阵，例如功率 25/30/35/40/45% × 进给 3000/3500/4000/4500/5000，每格 10mm 方块，选最满意的实心度再上正式件。深色亚克力批次差异大，这一步能省掉一块废料。
6. 跑正式件，**人在旁边看着**（约 3.2 分钟）。

## 5. 安全提示（照材料说，不要省）

- **通风排烟**：亚克力（PMMA）是必排烟材料，烟气刺鼻、刺激呼吸道，**排到室外**，不是"开个窗"，室内净化器只能减味不能替代排风。刻得越深、烟越浓。
- **明火风险**：亚克力、木材、纸板都会起火。**加工时人不能离开机器**，旁边备好灭火器/湿毛巾，知道急停和断电在哪；停机后再观察 1–2 分钟，暗火可能延后冒烟。
- **护目**：戴 445nm 蓝色激光防护镜（墨镜/太阳镜不算防护，反而更危险），优先用带外罩的机器，不要直视光斑和工件的反射散射光。
- **禁止加工**：PVC/乙烯基/仿皮、ABS、聚碳酸酯、玻纤/碳纤维、含铬鞣皮革、任何未知塑料（释放氯气、氰化物、六价铬等剧毒气体）。
- **参数只是起点**：本次给的是参数库的 20W 档基准值，批次、透镜、气压、焦距都会影响结果，必须先用废料实测微调。
- 二极管激光**不能切透明亚克力**（本次是雕刻，不受影响；将来若要切深色亚克力，20W 档是 100% 功率 / 600 mm/min / 2 遍）。
