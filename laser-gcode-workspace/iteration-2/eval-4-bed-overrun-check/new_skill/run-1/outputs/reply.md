## 二、参数摘要（20W 二极管 / 3mm 椴木 / 切穿）

| 项目 | 值 | 说明 |
|---|---|---|
| 材料 | `plywood_3mm`（椴木/桦木 3mm） | 参数库按材料+功率档位取值 |
| 激光器档位 | 20W 档 | 你用 20W，命中 20W 档，无需降级换算 |
| 功率 | **90% → `S900`**（`$30=1000`） | 真实光功率 ≈ 18W |
| 进给速度 | **F1000 mm/min**（≈16.7 mm/s） | 移动速度，不是功率 |
| 遍数 | **1 遍** | |
| 作业类型 | `cut`（M3 恒定功率） | |
| 预计耗时 | 约 0.2 分钟（38mm 版实切路径 143.5mm，≈9 秒；60mm 版 226.6mm，≈14 秒） | 不含对焦、装夹 |
| 输出原点 | 左下角，Y 向上（标准 CNC） | 原文件顶点是左上原点、Y 向下，已自动翻转 |
| 星形朝向 | 尖角朝上 | 顶点 (50,2) 被翻到最上方 Y=38.07 |

**为什么是这个档位**：`S` 是激光强度档位（0–1000），不是光功率本身，`S = 功率% × $30`。同一块 3mm 椴木在 10W 机器上要满功率切两遍（S1000/两遍），而 20W 机器功率更高，90% 单遍即可（`S900`、F1000、1 遍）——这就是为什么不能照抄别人的参数。

**如果你的 `$30` 不是 1000**（先用 `$$` 查一下），`S` 要按比例改：`S = 0.9 × $30`（例如 `$30=255` → `S230`）。另外确认 `$32=1` 已开启激光模式，否则不会调制激光。

## 三、关于「60mm 见方」的口径（这会影响你实际拿到的尺寸）

你给的顶点是归一化到 0–100 网格的，但星形本身只占网格的 91.3%（X 4.35–95.65、Y 2.00–88.83）。两种理解结果不同：

- **按网格整体映射到 60mm**（脚本默认原点＝整张 0–100 网格 → 60mm）：星形会变成 **54.78 × 52.10mm**，比你要的小 9%。
- **按图形包围盒映射**（`--frame` 显式声明 + `--fit contain`）：星形本体就是 **60.00 × 57.06mm**，这一版才是真正的「60mm 星形」，我按这个口径出了 `star_60mm_fit_cut.gcode`。

两个版本都保留，因为「60mm 见方」到底指成品还是画布只有你能定。**顺带一句**：激光切缝（kerf）约 0.15–0.25mm，成品会比文件尺寸略小一点；要精确到 0.1mm 就把目标尺寸放大一个切缝宽。

## 四、如果你想上机，三个选择

1. **缩尺寸（推荐，已就绪）**：用 `star_38mm_bed40_cut.gcode`，星形 38mm，四边留 ≈1mm。40×40 的床身通常还要被夹具、限位、对刀边吃掉一点，**实际可用行程多半小于 40mm**，所以别顶着 40 做。
2. **换机器/更大床身**：用 `star_60mm_fit_cut.gcode`，但需要行程 ≥60×57mm。
3. **分两次装夹拼接**：把星形中分两次切再粘。我不建议——星形中分接缝在尖角上很明显，二次装夹的定位误差（通常 0.2mm 以上）会让两半错位，接缝强度也差。真要做，别用这份文件，需要用支持分块/拼接的 CAM 出两块刀路。

改成别的尺寸，把目标尺寸换掉重新生成就行（不要手改 G 代码）：

```bash
python3 scripts/generate_gcode.py \
  --vertices "50.00,2.00 61.17,34.63 95.65,35.17 68.07,55.87 78.21,88.83 50.00,69.00 21.79,88.83 31.93,55.87 4.35,35.17 38.83,34.63" \
  --job cut --material plywood_3mm --laser-w 20 \
  --frame 4.35 2 91.3 86.83 --target-size 38 38 --fit contain --offset 1 1 \
  --bed 40 40 --output star_38mm_bed40_cut.gcode
```

## 五、上机前请务必做这几步

1. **先做测试网格**：在同一批 3mm 椴木废料上切一个 5×5 小方块矩阵，行＝功率（80%/90%/100%），列＝速度（800/1000/1200 mm/min），挑「刚好切透、边缘最不焦黑」的那格当基准。3mm 椴木胶水含量批次差异很大，表格参数只是起点。
2. **每次换材料重新对焦**——焦距偏差是参数失准的头号原因。
3. **开气泵（air assist）**：切椴木必开，显著减少焦边和火焰。想边缘更干净可以在料面贴一层美纹纸/转移膜。
4. **床身校验再确认**：先空跑（把功率调到 0 或用预览）确认光斑全程不出 40×40 范围，再正式出光。
5. 切不透时的正确顺序：先降速（1000 → 800 mm/min）→ 仍不行再补到 2 遍，别一上来就满功率多遍，会把 3mm 椴木烧焦甚至引燃。

## 六、安全红线（每次都要说，不是客套）

1. **人不能离开机器**，旁边备好灭火手段。激光加工是明火级别的火灾风险。
2. **戴对应波长（约 445–455nm）的激光防护镜 + 加外罩，不要直视光斑**，包括工件反射的散射光。
3. **必须排烟通风**，排到室外，不是「开窗」。椴木/MDF 的烟也有害。
4. **禁止加工**：PVC/乙烯基/仿皮、ABS、聚碳酸酯、玻纤/碳纤维、含铬鞣制皮革、未知塑料——会释放氯气、氰化物、六价铬等剧毒气体。椴木没问题。
5. **二极管激光不能切金属、也不能切透明亚克力**（光束直接穿透）。这次是椴木，可以切。
6. 所有参数都只是**起点**，先用废料验证再上正式料。
